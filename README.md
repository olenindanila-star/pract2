# Визуализатор графа зависимостей пакетов Rust (вариант 22)

Консольное (CLI) приложение на Python для анализа и визуализации графа
зависимостей пакетов менеджера пакетов Rust — **Cargo**.
Готовые менеджеры пакетов и сторонние библиотеки для получения
зависимостей не используются: только стандартная библиотека Python.

## Требования

- Python 3.8 или новее (Windows, Linux, macOS)
- сторонние библиотеки не нужны

## Запуск

Windows:

```
run.bat --package serde
```

Linux/macOS:

```
./run.sh --package serde
```

Или напрямую: `python src\main.py --package serde`.

## Тесты

```
python -m unittest discover -s tests
```

## Этап 1. Минимальный прототип с конфигурацией

Все настройки задаются **опциями командной строки**. При запуске
приложение выводит все параметры в формате `ключ = значение`.

### Параметры

| Опция | Описание | По умолчанию |
|---|---|---|
| `-p`, `--package` | имя анализируемого пакета (обязательно) | — |
| `-r`, `--repo` | URL-адрес репозитория или путь к файлу тестового репозитория | `https://index.crates.io` |
| `-m`, `--mode` | режим работы с репозиторием: `real` или `test` | `real` |
| `-o`, `--output` | имя файла с изображением графа (`.svg`) | `graph.svg` |
| `-a`, `--ascii-tree` | вывод зависимостей в виде ASCII-дерева: `yes` или `no` | `no` |
| `-f`, `--filter` | подстрока: пакеты, содержащие её, не анализируются | нет |
| `-h`, `--help` | справка | — |

### Обработка ошибок

| Параметр | Ошибка |
|---|---|
| `--package` | не задан; недопустимые символы; длиннее 64 символов; в режиме `test` — не большие латинские буквы |
| `--repo` | в режиме `real` — не URL (http/https); в режиме `test` — файл не найден |
| `--mode` | значение не `real` и не `test` |
| `--output` | расширение не `.svg`; пустое имя; папка не существует |
| `--ascii-tree` | значение не `yes` и не `no` |
| `--filter` | пустая подстрока или подстрока с пробелами |
| любой | неизвестная опция |

При ошибке выводится `Ошибка: ...` и программа завершается с кодом 1.

Демонстрация: `scripts\stage1_params.bat` (корректные запуски) и
`scripts\stage1_errors.bat` (ошибки для всех параметров).

### Пример

```
> run.bat -p tokio -m real -o tokio.svg -a yes -f test
package = tokio
repo = https://index.crates.io
mode = real
output = tokio.svg
ascii-tree = yes
filter = test

> run.bat -p serde -o graph.png
Ошибка: --output: файл должен иметь расширение .svg
```

## Структура проекта

| Путь | Назначение |
|---|---|
| `src/main.py` | точка входа |
| `src/config.py` | параметры командной строки и их проверка |
| `src/console.py` | настройка вывода UTF-8 (для Windows) |
| `tests/` | модульные тесты (`unittest`) |
| `examples/` | файлы тестовых репозиториев |
| `scripts/` | демонстрационные скрипты (`.bat`) |
| `run.bat`, `run.sh` | скрипты запуска |

## Функции

- `parse_config(argv)` — разбирает опции и проверяет каждую, возвращает
  `Config`; при ошибке бросает `ConfigError`.
- `validate_package`, `validate_repo`, `validate_mode`, `validate_output`,
  `validate_yes_no`, `validate_filter` — проверка отдельных параметров.
- `format_config(config)` — строки `ключ = значение` для вывода.
- `setup_console()` — включает UTF-8 для вывода в Windows.
